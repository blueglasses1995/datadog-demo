# Cursor用プロンプト集

このドキュメントには、Cursorでこのカリキュラムを効率的に学習するためのプロンプトテンプレートが含まれています。

## 🎯 使い方

1. Cursorを開く
2. 以下のプロンプトをコピー
3. `{}`で囲まれた部分を自分の状況に合わせて編集
4. Cursorのチャット(Cmd/Ctrl + L)に貼り付け
