# Datadog ハンズオン カリキュラム

このカリキュラムは、Datadogの主要機能を段階的に学習するための実践的なコースです。

## 🎯 学習目標

このコースを完了すると、以下ができるようになります：

- Datadogを使ったアプリケーションパフォーマンス監視（APM）
- インフラストラクチャの包括的な監視
- ログの収集・分析・トレースとの相関
- フロントエンドのユーザー体験監視（RUM）
- カスタムメトリクスとダッシュボードの作成
- 効果的なアラート設定と運用
- 本番環境でのDatadog活用

## 📚 カリキュラム構成

### 初級レベル（所要時間: 約4時間）

#### [レッスン1: 環境セットアップとDatadog基礎](./lesson-01-setup-and-basics.md)
**所要時間:** 60分
- Datadog概要と主要機能
- デモ環境のセットアップ
- Datadogアカウント作成とAPI Key設定
- 初回データ確認

**学習成果:**
- デモ環境を起動できる
- Datadogの基本的なUIナビゲーションができる

**学習成果:**

## 🛠️ 前提知識

### 必須
- 基本的なLinuxコマンド操作
- Docker / Docker Composeの基礎知識
- HTTP / REST APIの基本理解

### 推奨
- Python または JavaScript の基礎知識
- データベースの基本知識
- Webアプリケーションの基本アーキテクチャ理解

## 📝 使用するツール

- **Docker Desktop** - コンテナ実行環境
- **Webブラウザ** - Chrome, Firefox, Safari など
- **テキストエディタ** - VSCode, Cursor など
- **Datadog アカウント** - 無料トライアルOK

## 🚀 学習の進め方

### 推奨学習パス

1. **順番に学習** - レッスン1から順に進めることを推奨
2. **実習重視** - 各レッスンの実習を必ず実施
3. **確認問題** - 理解度を確認してから次へ進む
4. **復習** - わからない部分は戻って復習

### 学習スタイル別

#### 短期集中型（2-3日）
- 1日3-4レッスン
- まとめて実習
- 最後に総合演習

#### じっくり型（1-2週間）
- 1日1レッスン
- 各レッスン後に実環境で試す
- 理解を深めてから次へ

#### 必要な部分のみ
- 目次から必要なレッスンを選択
- ただしレッスン1は必須
- 前提レッスンを確認
